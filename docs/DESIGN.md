# Crunch Cartel visual direction

User decision, 13 October 2026: name the app **Crunch Cartel**, with a dark black theme and bright yellow accents. This explicitly replaces the specification's older ivory/green Warm Counter palette.

- Canvas `#090A09`; panels `#141614`; raised surfaces `#1D201C`.
- Bright yellow `#FFE500` for primary actions, selected navigation, icons and wordmark.
- Primary text `#F5F5EB`; secondary text `#B6BBAE`; boundaries `#373B33`.
- Use black text on yellow buttons. Do not put white body text on yellow.
- Segoe UI, strong compact headings, restrained 8/12px corners and 4px spacing increments.
- Keep status labels explicit; do not rely solely on color. No pulsing lights or decorative animation.
- Minimum 48px interactive targets, keyboard focus, F1 help and Ctrl+Home welcome navigation.
- Test 1366x768 physical resolution at 100%, 125% and 150% scale. Counter cart remains pinned; empty menu content can scroll within its own panel if needed. Preview welcome, setup and management pages can scroll.

The user's palette and local-execution constraint take precedence over generic UI skill design-generation scripts. The skill's contrast, hierarchy and keyboard guidance is applied directly; no design generator runs locally.
